# Agent Empire direction

A persistent home for projects, native agents and ordinary terminals. Keep the space atmosphere;
make the everyday loop easy: open a project, pull, ask an agent, run and test locally, then ask it
to commit and push.

The workspace now centers on Home, discovered Git projects, folder-derived sectors, manual
folders, planet tasks, persistent shells, the GitHub station and project anomalies. Agents stay
at their projects between tasks. Multiple agents may share a folder without requiring worktrees.

Campaign automation, saved ship designs/refits, prescribed launch roles, fleet orders, manual
relationships and managed worktree creation/merging have been removed from the product flow.
Legacy wire/session data remains readable; saved records and project files are preserved.

Future work should respond to using this smaller workflow. Priorities are readable attention
messages, reliable terminals and expressive procedural graphics. Add controls only when the
normal workflow needs them; do not rebuild a separate orchestration layer.
