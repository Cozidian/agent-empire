A station for the pull requests orbiting your projects.

Connect your account

Install GitHub CLI and authenticate it with gh auth login. Empire uses that existing authentication for projects with GitHub remotes. It does not ask you to paste a token into the UI.

Open the GitHub station for a fleet-wide overview. To see one repository, select its planet and press p, click its PR marker, or choose Pull requests in the project workspace. Esc returns to the view you came from.

Read the signals

MarkerMeaning
◇ PR NOpen PR count, including yours and other people's
!One of your PRs has failing checks
↗A non-draft PR requests your review
?Unavailable or stale cached data

Failing checks take priority over review requests. A quiet blue marker means open PRs without either signal; passing checks do not establish that a PR is ready to merge. Worktrees share their parent project's count.

The station refreshes up to 100 of your open PRs and 100 other open PRs per project every 150 seconds. Data older than 7½ minutes is marked stale. If GitHub is unavailable, you may still see cached results.

Review or prepare work

Tab cycles between all PRs, reviews requested from you, and your PRs. Enter opens the selected PR in your browser.

t prepares an ordinary task for that PR's project. Depending on the PR, the brief asks an agent to review it, fix failing checks or address feedback. Review briefs ask for findings without posting them. Other briefs can include pushing changes, so inspect the exact instruction before sending.

Use the native terminal to follow the task, then inspect its result in GitHub. Empire's station is a view of GitHub state, not an approval to merge or deploy.
