Spend your attention where it helps the fleet move.

Find who needs you

On the galaxy, Tab selects the next agent needing you. Uppercase C opens the attention list across projects. Home also prioritizes projects with input or review waiting.

Permission questions appear as incoming transmissions with the requested command highlighted. Use a displayed number key to answer, or c to open comms and inspect the conversation. Read the request before approving it. When the galaxy is closed, desktop notifications can report questions and completed turns.

Inspect a finding

Uppercase A opens anomalies across the galaxy; lowercase a inside a project filters to that world. Findings include detected Git conflicts and failing CI, plus reported bugs, unclear behavior, documentation gaps and improvement ideas.

Each finding keeps its source and evidence. Reported findings are labelled as not independently verified. Select one and press t to prepare an investigation task. Read and edit the brief before sending; its request for a read-only investigation does not replace the agent's permission controls.

Automatic findings resolve when a fresh survey confirms recovery. An agent finishing an investigation is not proof that the original issue is fixed.

Report from a terminal

You or an agent can record a discovery without starting the daemon:

empire anomaly /path/to/project 'Confusing login flow' \
  'The callback discards the destination; see src/auth.rs.' 'agent report'

Use concrete evidence and a useful source label. Keep secrets and personal data out of report text if you plan to share it.

Optional report severity

With EMPIRE_ADVISOR_SEVERITY=1, PROVIDER_API_KEY and an explicit PROVIDER_BASE_URL, a compatible typed-decision service can score reports to order the attention list. Report titles, evidence and project basenames leave your machine. This is off by default; failures and uncertain answers preserve the normal ordering. The service must implement POST /v1/advice, and PROVIDER_DEFAULT_MODEL selects its model. This is not a generic chat API.
