A task is a prompt waiting for a ship on one particular world.

Write a brief

Select a project and press t. Describe the outcome, the relevant context and how you want the result checked. A useful brief might be:

Fix the settings panel at narrow widths. Keep all actions reachable at 390 pixels, check keyboard navigation, and show the changes before committing.

Enter sends the task. Alt+Enter, Shift+Enter or Ctrl+J inserts a newline. Pasted line breaks are preserved.

Choose the destination

Tab switches between the next available agent on this planet and launching a new ship. With no live agents, the composer defaults to a new launch. The species picker uses ↑/↓, matching its arrows.

In a multiline prompt, Up and Down first move between lines. At the first or last line, they select the previous or next species. Left and Right remain text-cursor keys.

Queued tasks go to one available agent in the exact project folder. If every agent is working, the task waits. An agent waiting for permission is not free to accept another task.

Attach screenshots

ControlAction
Ctrl+VPaste clipboard text or attach a clipboard image
Ctrl+OAttach an image using a path typed into the composer
Drop image pathsAttach the referenced images
Ctrl+XRemove the most recent attachment

A task can include up to eight images, at most 20 MiB each. Empire copies them into its private screenshot directory so the task still works if the original files move. The receiving agent needs its own image-viewing capability.

Failed delivery keeps your draft. Cancelling the composer removes unsent image copies. Submitted attachments become saved task data, so review images for private information before sharing them elsewhere.

Follow the task

Press uppercase L on the galaxy to open the selected planet's task history. Open the agent's terminal to see its actual work or answer a question. Completing a turn signals that the result is ready to check, not that it passed its acceptance criteria.

For a conversation already in progress, you can always type directly into the agent's native terminal instead of creating another queued task.

Optional species suggestions

With advisor configuration and EMPIRE_ADVISOR_ROUTE=1, the composer can suggest an installed species after a one-second typing pause. It sends the project basename and up to 4,000 characters of task text to the configured service. A confident result can preselect the species; choosing one yourself takes precedence. Nothing is launched until you send the task.

Reviewing finished missions

EMPIRE_ADVISOR_OUTCOME=1 adds “Looks failed”, “Partly done” or “Needs review” warnings to finished turns and the mission log. Without advisor configuration it scans for explicit failure phrases locally. With configuration it sends a bounded mission excerpt and terminal output with common secret patterns removed. Redaction cannot detect every secret. A warning is a prompt to inspect the work; a quiet result does not verify success.
