Find the key for the view you are in.

Uppercase and lowercase keys can do different things. The footer shows contextual actions; ? opens help on the galaxy.

Galaxy

KeyAction

t / b / eTask / new shell / launch agent on the selected project
c / 1–9Open the incoming transmission, else selected ship / answer the transmission
xDismiss a selected ship after confirmation, or hide a selected planet
iShip information
Tab / CNext agent needing you / attention list
H / n / VHome / add one folder / manage roots and folders
pPull requests for the selected project
R / AResearch Station / anomalies
L / SSelected planet's task history / situation log
↑ ↓ / j kSelect in the outliner
g / GFirst / last outliner entry
w a s d / dragPan the map
+ − / wheelZoom
z / f / oFit the galaxy / focus selection / toggle outliner
m / MMute alert sounds / mute music
? / qHelp / leave the galaxy while sessions keep running
