The everyday loop

  1. Open a world. Select a project and press Enter to see its agents, terminals and Git state.
  2. Give it work. Press t to write a task, or e to launch an agent and talk directly.
  3. Try the result yourself. Press b to open an ordinary shell for tests, a development server or Git.
  4. Follow the signals. Return to the galaxy and press Tab to find the next agent that needs you.
  5. Leave and come back. Press q on the galaxy. The daemon keeps sessions alive.
Done means ready to check. An agent finishing a turn does not prove the change is correct. Review its output, run your checks, and decide what to commit or publish.
